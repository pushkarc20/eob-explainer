# Security

This is a portfolio project that works on **synthetic data only**. It is not a production system and has no real users.

## Please do not post real health data

Never put real health, insurance or personal information, API keys, or tokens in an issue, pull request, or discussion. If you posted a real key by accident, delete it in the console of the provider that issued it first, then tell me.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") if it is available on this repository. If it is not, open an issue titled "Security" **without technical details**, and I will arrange a private channel.

## Scope

In scope: the privacy and safety claims in `docs/privacy.md` and `docs/stateless.md` (for example, a way to make the app send identifiers to a model, write documents to disk, or skip the consent step).
Out of scope: issues in third-party libraries (report those upstream), and anything that needs real patient data to demonstrate.
